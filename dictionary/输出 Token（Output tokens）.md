[模型](./模型（Model）.md)生成并返回的 [Token](./Token（词元）.md)。由于生成输出需要消耗更多算力，其计费单价高于[输入 Token](./输入%20Token（Input%20tokens）.md)——通常大约是输入单价的五倍。

模型写出的所有内容都算在内：你读到的正文、它输出的代码、[工具调用](./工具调用（Tool%20call）.md)，以及模型在回答前进行的任何深度思考（extended thinking）。最后一项常常让人意外——即使 [Harness](./Harness（驾驭框架）.md) 通常不会把推理过程展示给你看，推理 Token 依然按输出 Token 计费，而调高[推理强度](./推理强度（Effort）.md)就会消耗更多这类 Token。

输出 Token 也决定了[会话](./会话（Session）.md)的响应节奏。模型读取输入的速度很快，但生成输出时是一个 Token 接一个 Token 地吐出，因此当某个[轮次](./轮次（Turn）.md)让你觉得很慢时，几乎总是因为正在写入输出，而不是在读取输入。等待时间长，通常意味着即将有一段很长的回答。

_用法示例：_

“输入明明很小，这次重构会话怎么额度烧得这么快？”

“Agent 在重写整个文件，而不是只打补丁。输出 Token 的单价大约是输入 Token 的五倍——让它改成输出局部编辑，账单立马就会降下来。”
