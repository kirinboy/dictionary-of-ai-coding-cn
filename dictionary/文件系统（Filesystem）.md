[Agent](./Agent（智能体）.md) 从中读取、写入并在其中执行命令的文件与目录树——编程 Agent 默认的[环境](./环境（Environment）.md)类型。[AGENTS.md](./AGENTS.md.md)、[Skill](./Skill（技能）.md)、源代码、构建脚本以及[工具](./工具（Tool）.md)配置都保存在文件系统中。当一个 [Harness](./Harness（驾驭框架）.md)“在你的项目中启动”时，它实际上是在将 Agent 指向一个文件系统。

Agent 只能通过[工具调用](./工具调用（Tool%20call）.md)来接触文件系统——读取文件、写入文件或运行 Shell 命令。在工具调用加载之前，磁盘上的任何内容都不会进入[上下文窗口](./上下文窗口（Context%20window）.md)，这也正是 Agent 能够在远大于上下文窗口的代码库中工作的原因：文件系统容纳了一切，而上下文只保存当前任务读取过的内容。有些 Harness 确实会默认将当前目录的文件名列表加载到上下文窗口中——不是文件内容，仅仅是目录树——这些文件名充当了[上下文指针](./上下文指针（Context%20pointer）.md)：Agent 能看到有哪些文件存在，再按需读取所需的文件。

而且文件系统是与你共享的。Agent 编辑的文件，正是你在编辑器里打开、在 git 中查看 diff 的同一批文件——文件系统就是你审查 Agent 工作成果的共同工作空间。

_用法示例：_

“为什么它没有读取我的 AGENTS.md？”

“它运行在另一个文件系统上——[沙箱](./沙箱（Sandbox）.md)挂载的是父目录，而不是项目根目录。重新指向正确的目录即可。”
