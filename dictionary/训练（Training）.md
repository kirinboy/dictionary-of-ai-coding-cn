设定[模型](./模型（Model）.md)[参数](./参数（Parameters）.md)的过程：让模型接触海量文本，并不断调整参数以改进[下一个 Token 预测](./下一个%20Token%20预测（Next-token%20prediction）.md)的准确度。这是一个由[模型提供商](./模型提供商（Model%20provider）.md)一次性完成、成本极高的过程。它既包括预训练（大规模基础训练），也包括后训练（后续的指令遵循、安全性对齐等优化）；在本词典的讨论层级上，这两者的区别并不重要。

其核心机制是大规模重复：向模型展示一段文本，让它预测下一个 [Token](./Token（词元）.md)，再将参数微调向实际的下一个 Token，如此在数万亿个 Token 上反复迭代。没有任何信息是以“事实”或“规则”的形式单独存储的——模型“知道”的一切，都是在不断提升预测能力的过程中产生的副产品，被压缩进参数里形成[参数知识](./参数知识（Parametric%20knowledge）.md)。

这带来了两个影响日常使用的后果。首先，训练会在某个时间点结束，因此模型存在[知识截止日期](./知识截止日期（Knowledge%20cutoff）.md)——它没有见过你上个月刚升级的那个库的新版本。其次，训练不是你能亲自去做的事：当模型不了解你的代码库、编码规范或内部 API 时，解决办法绝不是“去教模型”，而是把这些资料放进[上下文](./上下文（Context）.md)里——这才是你真正能掌控的输入杠杆。

_用法示例：_

“我们能让它学会我们的内部 API 吗？”

“靠训练是不行的——那是模型提供商耗时数月才能做完的事。把 API 文档放进上下文里吧，这才是你手头真正能用的手段。”
